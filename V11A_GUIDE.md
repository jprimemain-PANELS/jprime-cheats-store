# v11a - what is new (no SQL needed; run 007 from v10 if you have not)

1. **Branding live preview** - under the Branding tab there is a preview of your real website (Phone / Desktop / Refresh). Press Save and it reloads by itself. (Security header changed from DENY to SAMEORIGIN so your own admin page can show your own site; other websites still cannot frame it.)
2. **Profile page** - the round profile button now opens /profile: role, wallet, number of purchases, total spent, change password, full purchase history with copy key.
3. **Product categories** - Add/Edit product -> Category -> "+ New category..." (owner and co-admin). Type a name like "Gaming Tools"; it becomes its own tab on your website (desktop menu, phone menu and category buttons) once it has a product. Mobile / PC / iOS stay as they were.
4. Fonts and header buttons fixed earlier in v10b are included.

Not in this batch yet: mobile/beginner pass over the co-admin pages, customer->reseller upgrade, maintenance + product-delete sync, security report.
